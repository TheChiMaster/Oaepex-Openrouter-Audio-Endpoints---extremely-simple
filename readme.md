# Oaepex: Openrouter Audio Endpoints - extremely simple
Streamlines generation of audio content  via openrouter. 
Don't curl your way around the universe like you have a bicep that big. Instead, use my tool and give me a star!

## Architecture:
- Simple python backend sends requests to the greatest AI agrigator  in the world
- A front end makes it pretty, pressable and playable for you
- Fully accessible for screen reading software
- You only need to know how to get an API key and use a mouse / keyboard

## Requirements
- API key from Openrouter, [Click here to get one](https://openrouter.ai/workspaces/default/keys)

Don't have any ideas of what to generate? That's ok! 
Inspiration comes when you start playing around. 


# Disclaimers:
- This tool is fully open source, audit everything
- You are  solely responsible  for the content you create
- No information is sent to other third party servers, except for Openrouter
- Information stored on device:
 - API keys, securely stored as a  secret 
 - Generated content is saved in your designated output folder, you select this on the app's first launch
 - Prompts sent to models via Openrouter are subject to the provider's retention policies, which you can configure in your account's [settings](https://openrouter.ai/settings/privacy)
